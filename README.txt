SHOP EASE — WORKING FINAL VERSION
===================================

This version has the CSS and JavaScript EMBEDDED INSIDE EVERY HTML PAGE.
Therefore the design will still appear when pages are opened directly
from your computer using double-click.

HOW TO USE
1. Extract the ZIP completely.
2. Open the ShopEase_WORKING_FINAL folder.
3. Double-click index.html.
4. Click Home, Shop, Categories, Electronics, Fashion, Footwear,
   Accessories, Deals, Product, Cart, Checkout, About and Contact.
5. Every page contains its own styling, so you should not see an
   unstyled / plain HTML page.

Internet is recommended for the online product photographs and fonts.

This is a front-end college project. Payments, database, authentication
and real order processing are not connected.
